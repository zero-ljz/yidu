译读

划词即译，选文即读。

一款轻量的 Windows 划词翻译与在线朗读工具。无需切换窗口，也无需申请 API Key。

在 Microsoft Store 中获取 查看源码

适用于 Windows 10 / 11

翻译 Ctrl+F1
朗读 Ctrl+F2
配置 托盘右键菜单

核心功能

少一步切换，多一点专注

中英互译

自动识别文本语言，长文本自动分段，并在请求不稳定时重试。

在线朗读

提供普通话、方言、粤语、台湾腔及英语等多种在线音色。

就近浮窗

结果显示在鼠标附近，支持复制、朗读、置顶与自由拖动。

使用方式

选中文字，按下快捷键

没有选中文字时，译读会打开输入窗口。快捷键和显示位置均可调整。
01
翻译选中的文本 自动选择中文或英文作为目标语言
Ctrl+F1
02
朗读选中的文本 通过输入窗口选择喜欢的在线音色
Ctrl+F2

立即使用

获取译读

通过 Microsoft Store 安装译读，并自动获取后续更新。

在 Microsoft Store 中获取 查看版本说明

网络与隐私

译读可使用腾讯、有道或谷歌的免费翻译接口处理翻译请求，并使用 Microsoft Edge 在线语音服务合成朗读音频。请勿提交不适合上传到第三方服务的敏感文本。
