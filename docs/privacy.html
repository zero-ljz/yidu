隐私与数据处理

隐私政策

本政策说明译读 Windows 应用及官方网站会处理哪些数据、为何处理，以及你可以如何控制这些数据。

生效日期：2026 年 8 月 29 日 最近更新：2026 年 8 月 29 日

本页目录 适用范围 数据处理 第三方服务 本地数据 官方网站 你的选择 安全与变更 联系我们

译读是一款免费、开源的 Windows 工具。应用不要求注册账户，也不包含广告、用户行为分析或由开发者运营的数据收集服务器。只有当你主动使用翻译或在线朗读功能时，相应文本才会发送给你选择或功能所需的第三方服务。

1. 适用范围

本政策适用于译读 Windows 应用以及 yidu.iapp.run 官方网站。通过本站访问 GitHub、翻译服务或其他第三方网站后，对方的数据处理由其自身隐私政策约束。

2. 我们处理的数据

译读仅为完成你发起的操作处理必要数据。主要数据流如下：

功能 处理的数据 接收方 目的
划词或手动输入 你选中或输入的文本 仅在本机处理，直至你执行翻译或朗读 获取待处理内容
在线翻译 待翻译文本、源语言和目标语言 腾讯、有道或 Google 中你当前选择的服务 返回翻译结果
在线朗读 待朗读文本和所选音色标识 Microsoft 在线语音服务 合成并返回音频

第三方服务还可能自动接收提供网络服务所必需的信息，例如 IP 地址、请求时间、User-Agent 和连接信息。译读开发者不通过应用接收这些请求内容。

3. 第三方在线服务

译读使用无需用户 API Key 的第三方在线接口。接口的可用性、处理方式和保留期限由相应服务提供方决定，可能随其政策调整。

  • 腾讯翻译：翻译文本会发送至腾讯相关翻译接口。参见腾讯隐私保护平台。
  • 有道翻译：翻译文本会发送至有道翻译接口。参见网易有道隐私政策。
  • Google 翻译：翻译文本会发送至 Google 翻译接口。参见Google 隐私权政策。
  • Microsoft 在线语音：待朗读文本及音色标识会发送至 Microsoft Edge 在线语音服务。参见Microsoft 隐私声明。

请勿使用译读处理不适合提供给上述第三方的密码、身份信息、商业秘密、医疗信息或其他敏感内容。

4. 本地存储与临时文件

应用配置

源码版和绿色版在程序目录的 YiDu.ini 中保存设置，MSIX 版本则使用 %APPDATA%\YiDu\YiDu.ini。其中包含快捷键、翻译服务、语音角色、在线服务授权、管理员启动和结果显示位置等设置，不包含翻译历史或账户信息，也不会由译读发送给开发者。

剪贴板

为读取当前选中的文本，译读会在本机临时访问剪贴板，并尽力恢复原有内容。只有当你主动选择“复制结果”时，翻译结果才会写入剪贴板。

语音临时文件

在线朗读期间，译读会在 Windows 临时目录创建请求、状态和音频文件，并在正常停止、完成或退出时删除。若应用或系统异常终止，个别临时文件可能暂时保留，可通过 Windows 临时文件清理功能移除。

开机自启

仅当你主动开启“开机自启”时，绿色版才会在 Windows 启动目录创建快捷方式；MSIX 版本则通过 Windows StartupTask API 请求启用系统管理的启动任务。关闭该选项会删除快捷方式或禁用对应启动任务。

5. 官方网站

官方网站是静态页面，不设置第一方 Cookie，不使用本地存储，也未接入广告、访问分析或跟踪脚本。页面从 unpkg CDN 加载图标脚本；浏览器访问该资源时，CDN 可能收到 IP 地址、User-Agent 和请求时间等标准网络信息。

当你点击下载、源码或问题反馈链接时，将访问 GitHub；点击邮件链接时，将由你的本地邮件应用处理。相关服务的数据处理受其各自政策约束。

6. 你的选择与控制

  • 你可以在托盘菜单中选择腾讯、有道或 Google 作为翻译服务。
  • 首次运行时，你可以选择是否启用在线翻译和在线朗读；未同意前，译读不会启动在线语音工作进程或发送文本。
  • 你可以随时从托盘菜单打开“在线服务与隐私”，撤回或重新给予同意。
  • 你可以退出应用并删除 YiDu.ini，清除本地保存的应用设置。
  • 你可以使用 Windows 的临时文件清理功能移除异常退出后可能残留的语音文件。
  • 译读源码公开在 GitHub，你可以审查、修改或自行构建应用。

7. 安全与政策变更

译读通过 HTTPS 或加密的 WebSocket 连接第三方在线服务，但任何互联网传输都无法保证绝对安全。请根据文本敏感程度谨慎使用在线功能。

当应用功能、第三方服务或数据处理方式发生实质变化时，本页面将同步更新，并修改页面顶部的“最近更新”日期。建议在升级应用后查看最新版本。

如对本政策或译读的数据处理方式有疑问，请发送邮件至 hi@iapp.run，或通过 GitHub Issues 提交问题。
